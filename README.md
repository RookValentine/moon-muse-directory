# ☾ Moon & Muse

**An independent, creator-first directory for adult professionals and online creators.**

Moon & Muse is a directory concept designed to help adults discover independent online creators and professionals while prioritizing privacy, creator autonomy, transparent access settings, and clear boundaries.

## ✦ About the Project

Moon & Muse is being developed with a focus on making creator discovery more straightforward, respectful, and privacy-conscious.

The platform is intended to support individual creators by giving them control over their public profiles, professional contact methods, and how their information is shared.

### Core Principles

- **Creator autonomy:** Creators control their profiles and contact visibility.
- **Privacy by design:** Public profiles do not display country or location fields.
- **Transparent access:** Token-locked contact methods display their costs before an unlock is confirmed.
- **Earned verification:** Verification statuses are intended to reflect completed checks rather than unsupported claims.
- **Private favorites:** Users can save profiles and keep personal notes privately.
- **Positive feedback:** The planned launch feedback system uses four compliment tags rather than public star ratings or written reviews.

## 🛠️ Current Development Status

**Status: Early prototype**

The current version is a standalone HTML, CSS, and JavaScript prototype intended for interface development and experimentation.

It includes sample creator profiles, a directory interface, profile pages, a creator dashboard, and simulated interactions.

**Important limitations:**

- Authentication is not connected to a live account system.
- Payments and token purchases are not live.
- Verification is not connected to a verification provider.
- Sample balances and interactions are demonstration data.
- Data persistence, production security, and backend functionality still need to be implemented.

Do not use the current prototype to process real payments, collect sensitive personal information, or represent a user as genuinely verified.

## 🔒 Privacy & Safety

Privacy and creator control are central design goals for Moon & Muse.

The intended platform design emphasizes:

- No public country or location fields on creator profiles
- Creator-controlled visibility for professional contact methods
- Private favorites and personal notes
- Transparent contact-unlock costs
- Reporting and moderation processes
- Careful handling of account, verification, and financial information

These are project goals, not a claim that every protection is already implemented in the current prototype.
